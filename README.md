## Sobre o projeto

O Planej.ai é uma aplicação web desenvolvida para ajudar o usuário a compreender melhor sua situação financeira.

A aplicação coleta informações sobre renda, gastos, dívidas, reserva financeira, objetivo e prazo. A partir desses dados, utiliza inteligência artificial para gerar um diagnóstico personalizado e apresentar recomendações e próximos passos.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Google Gemini API
- Vercel

## Funcionalidades

- Simulação financeira
- Validação das respostas
- Resumo dos dados informados
- Diagnóstico financeiro gerado por IA
- Recomendações personalizadas
- Próximos passos
- Interface responsiva
